## Bloque anonimo

ver -> DBMS -> +

```sql
DECLARE
    v_nombre_completo VARCHAR(255) :='ALAN BRITO';
    v_renta           cliente.renta_cli%TYPE;
BEGIN
    SELECT
    nombre_cli || ' ' || appaterno_cli || ' ' || apmaterno_cli  AS nombre,
    renta_cli
    INTO
        v_nombre_completo,
        v_renta
    FROM cliente
    WHERE numrut_cli = 12251882
    ;

    DBMS_OUTPUT.PUT_LINE('NOMBRE: ' || v_nombre_completo);
    DBMS_OUTPUT.PUT_LINE('RENTA: ' || TO_CHAR(v_renta, '999g999g999'));

EXCEPTION
    WHEN OTHERS THEN
    DBMS_OUTPUT.PUT_LINE('ERROR');
END;
```
