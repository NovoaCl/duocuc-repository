### Arquitectura de software

Define la forma en que se organiza y estructura una aplicacion

### MVVN

Model - View - ViewModel(MVC para android)
Patron, arquitectura utilizada en dev mobile
Separa interfaz de usuario, logica de negocio, mediante un intermediario ViewModel

- ui/           : user interface
- viewmodel/    : logica de presentacion
- model/        : Clases de datos
- repository/   : Comunicacion con fuente de datos.
